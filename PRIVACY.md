# Privacy Policy

Social Network Daily Timer does not collect, transmit, sell, or share any user
data remotely.

The extension stores only the data necessary to provide its timer
functionality, including the user's daily social-media view time. This data is
stored locally in the user's browser using Chrome's local extension storage. It
never leaves the user's device.

Users can remove the locally stored data by uninstalling the extension or
clearing the extension's local storage.
